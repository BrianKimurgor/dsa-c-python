# Bare Metal to Python

An interactive, single-file course in data structures and algorithms: first in C, where nothing is hidden, then in Python.

## Read it

Open `bare-metal-to-python.html` in any browser. It works offline. No build step, no dependencies.

## What is inside

42 chapters in six parts:

1. **Start here** – a method for reading code, and setting up gcc and Python on Windows.
2. **C before DSA** – types, control flow, functions, arrays, pointers, structs, heap memory, Big-O.
3. **DSA in C** – dynamic arrays, searching, sorting, linked lists, stacks, queues, recursion, hash tables, binary search trees, heaps, graphs, dynamic programming.
4. **The same ideas in Python** – what Python hides, and every structure and algorithm side by side with its C version.
5. **The problem ladder** – 35 problems in five levels, with hints and solutions in both languages.
6. **Keep going** – a reading list, a twelve-month plan, and the ML infrastructure lane: a neural network in C, CUDA, inference engines, and technical writing.

## Interactive features

- Click any marked line of code for an explanation.
- 19 step-through visualizers that highlight the executing line while the data changes.
- Predict-before-you-run boxes and check-yourself quizzes.
- Progress tracking, stored in your browser only.

## Layout

The whole book is one HTML file with inline CSS and JavaScript. Fonts load from Google Fonts and fall back to system fonts offline.
